# Veille Legaltech et Produit

Page d’index des éditions de la newsletter.

## Fichiers

- `index.html` : liste les éditions disponibles.
- `editions/2026-10-05.html` : édition du 28 septembre au 4 octobre 2026.

À chaque nouvelle édition, ajoute la page dans `editions/` puis ajoute un lien en haut de la liste dans `index.html`. Le dépôt est statique et peut être déployé depuis sa racine sur Vercel.
